Esse módulo fornece uma coleção de relatórios em pdf e excel utilizados na ABCD USP. Os relatórios estão todos disponíveis no rota: /indicadores

Criando um relatórios:

1. Colocar o link no IndexController
2. Criar as 3 rotas 
3. Criar o controller para esse relatório
4. Criar a classe que vai de fato tratar os dados na pasta Relatorios, implementar os métodos prepareData e createHtmlTable
